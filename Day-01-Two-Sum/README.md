# Day 1 - Two Sum

## Problem
Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.

## Approach
Used a brute-force approach with two nested loops.

1. Traverse each element using the outer loop.
2. Compare it with every subsequent element.
3. If the sum equals the target, return the indices.

## Time Complexity
O(n²)

## Space Complexity
O(1)

## Language
Java
